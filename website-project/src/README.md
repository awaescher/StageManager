# README.md

このプロジェクトは、macOSのStage ManagerをMicrosoft Windowsに持ち込むための実験的なアプローチです。

## 概要

このプロトタイプは、アプリケーションをプロセスごとにグループ化します。左側の「シーン」を切り替えることで、他のウィンドウやデスクトップアイコンを隠し、集中力を高めることができます。

ウィンドウは、シーンの左側にドラッグすることで、別のシーンに移動できます。

## 使用方法

[リリースタブ](https://github.com/awaescher/StageManager/releases/)から実行可能ファイルをダウンロードして実行するか、以下の手順でプロジェクトをクローンして実行します。
- このリポジトリをクローン
- リポジトリディレクトリに移動
- `dotnet run --project StageManager`を実行

終了するには、アプリのトレイアイコンを見つけ（Windowsがそれをオーバーフロー メニューに移動する場合があります）、そのコンテキストメニューを使用してアプリを閉じます。

## 要件

- Windows 10 バージョン 2004 以降
- [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download)
