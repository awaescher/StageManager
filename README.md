# Stage Manager for Windows

Stage Manager for Windowsのランディングページです。このプロジェクトは[Stage Manager](https://github.com/awaescher/StageManager)のウェブサイトを提供します。

## 開発

このウェブサイトは純粋なHTML、CSS、JavaScriptで構築されています。特別なビルドプロセスは必要ありません。

## デプロイ

このウェブサイトはGitHub Pagesを使用してホストされています。`main`ブランチへのプッシュ時に自動的にデプロイされます。
